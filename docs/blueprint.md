# **App Name**: FTE Vision

## Core Features:

- Access Control: Implement role-based access to ensure data security and appropriate user permissions (Administrator, Account Manager, Team Lead, Viewer).
- FTE Management: Allow for input and editing of employee FTE data, including manager, job title, and team lead designation, with assignment capabilities in increments of 0.05.
- FTE Reporting: Generate comprehensive reports on FTE utilization by account, leader, region, and employee, including historical trend analysis and data export in common formats.
- Weekly FTE Allocation: Streamline weekly FTE allocation with an intuitive UI that allows entry for the current and one future week ending on Sundays, ensuring individual allocations do not exceed 1.0.
- FTE Forecasting: Provide monthly forecasts by using the prior four reported periods to generate future projections; this tool prompts users to confirm and update their forecasts as needed.
- Automated User Sync: Automate the weekly synchronization of active users from regional HR systems to manage user access, and automate single sign on (SSO) with Randstad.
- Centralized Repository: Establish a single source of truth for all FTE-related data that can feed into IFS reporting, improving productivity analysis across GBS.

## Style Guidelines:

- Use #255CA9 (a saturated, bright blue derived from the blue in the Randstad color palette) to ground the interface in the Randstad brand.
- Use #B2CFF2 (a highly desaturated light blue of the same hue) to maintain the overall branding, while creating a professional appearance.
- Implement #BAD808 (a contrasting bright yellow-green) to call attention to key data and interactive elements, for greater usability.
- Use 'Inter' (a grotesque sans-serif font) for all text.
- Note: currently only Google Fonts are supported.
- Employ a consistent, modern icon set aligned with Randstad's brand guidelines for clear and efficient navigation.
- Adopt a clean and structured layout, emphasizing key data and improving the visual hierarchy for different user roles (e.g., admins, managers, employees).
- Incorporate subtle transitions and feedback animations to enhance user interaction and provide clear visual cues, ensuring a smooth user experience.
